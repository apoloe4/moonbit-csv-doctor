# CSV Doctor 项目说明

## 目标

解决导入订单、表单或业务 CSV 前人工检查慢、错误定位困难的问题。提供可复用的 MoonBit 核心、自动化命令行和浏览器演示，所有分析均在本机完成。

## 本期交付

1. 原创 CSV 状态机：引号、转义、多行、BOM、自定义分隔符与物理行号。
2. 五类检查：非空、类型、数值范围、枚举、唯一性；同时检查记录列数。
3. 严格配置校验：拼错字段、缺失列等会中止检查。
4. 结构化诊断与统计、JSON/HTML 报告、中文演示界面、CLI 退出码。
5. 字段级 UTF-8/UTF-16 范围、原文高亮、修复预览、确认替换、撤销与 SHA-256 修复记录。
6. 自动化测试、公开源码和 MIT 许可。

## 技术选择

MoonBit 编译为 JavaScript，浏览器 Worker 和 Node.js 复用 `analyze(csv, rules_json)`。核心不依赖 DOM、文件系统或网络。JS 处理 UI、文件读写、原文补丁/撤销和报告 HTML，验证规则不在 JS 中重新实现。

解析为单次扫描；验证约为记录数 × 规则数。唯一性使用散列表。整个 CSV 和问题集合保存在内存中，因此限制文件大小，不宣称支持海量流式分析。

## 三分钟演示

1. `npm start` 打开页面，点击“载入问题示例”。说明 6 行数据、3 行异常、6 个问题。
2. 筛选重复值，展示原始行号与首次出现位置。
3. 展示负金额、缺失客户、未知状态和布尔类型错误。
4. 选择负金额字段，输入 20 并预览；确认后问题数 6→5，撤销后 5→6。导出修复 CSV、原始 CSV 和修改记录。
5. 命令行运行 clean.csv：退出 0；orders.csv：退出 1。说明如何接入 CI。
6. 展示 MoonBit 核心和测试命令，解释引号状态机及多行行号追踪。
